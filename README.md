Personal Finance Spending Clusters

A machine learning project that analyzes personal finance transaction data and groups spending habits into meaningful clusters using the K-Means clustering algorithm. This helps users identify spending patterns, understand financial behavior, and make smarter budgeting decisions.

🚀 Features
Import and analyze transaction data
Data cleaning and normalization
Spending pattern identification
K-Means clustering implementation
Interactive data visualization
Cluster-based financial insights
Easy-to-understand dashboards

Matplotlib

Results

The model groups users' spending transactions into clusters based on factors such as:

Monthly expenditure
Transaction frequency
Category-wise spending
Savings behavior

These clusters help identify:

High spenders
Budget-conscious users
Balanced spenders
Irregular spending patterns
